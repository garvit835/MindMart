# MindMart

MindMart is an AI-powered mental wellness and sustainable marketplace platform.

## Architecture (Phase 1)
- **Frontend**: React Native with Expo and Expo Router (TypeScript).
- **Backend**: NodeJS with Express (TypeScript).
- **Database/Auth**: Supabase PostgreSQL.

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm start
```

### Backend
```bash
cd backend
npm install
npm run dev
```

### Database
Run the SQL queries in `supabase/schema.sql` on your Supabase dashboard SQL Editor to create the necessary tables and Row-Level Security (RLS) policies.
